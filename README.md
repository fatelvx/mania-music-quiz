# mania music quiz

osu!mania 猜歌遊戲，三種模式：

- 🎵 **聽歌猜曲**：播官方 preview 音樂
- 👀 **看譜猜歌**：靜音，只看 note 捲動
- ⚡ **先譜後歌**：先只有譜面（2 分），時間過半放音樂（1 分）

看譜模式可以選 **隨機段落**（每張譜除了 preview 那段，另外存了最多 3 段），計分可以選 **搶答**（越快答對分數越高，10～2 分）。

## 題庫

三種排序，都可以只取前 100 / 250 / 500 / 1000 組（越小越大眾）：

- **🔥 pp 圖**：從 4K / 7K 排行 1～10000 名平均抽樣約 1500 位玩家，統計誰的 top 100 裡最常出現哪些圖
- **🏛️ 經典**：mania 難度的總遊玩次數
- **🎲 混合**：兩種排名取較前面的

## 多人

開房會拿到 5 碼房號，朋友輸入房號或打開連結就能加入。

- 連線用 WebRTC（PeerJS 公用伺服器只負責牽線），玩家之間全部直連，網站本身仍是純靜態
- 房主負責出題、計分；每個人都存一份遊戲狀態
- **房主斷線會自動換人**：最早加入、還在線上的人接手（約 2 秒），這題的答案會重送給新房主，遊戲不中斷
- 斷線的人用同一個暱稱重新加入，可以拿回原本的分數
- 房間內有聊天室（加入、離線、換房主會自動提示）
- 連不上時可以按「連線測試」看 NAT 類型；嚴格的網路需要在 `docs/config.js` 設定 TURN 中繼

限制：少數很嚴格的網路（對稱式 NAT）可能連不上；房主理論上看得到題目答案，適合跟朋友玩。

## 架構

```bash
cp .env.example .env   # 填入 OSU_CLIENT_ID / OSU_CLIENT_SECRET
node build.js          # 產生 docs/data/pool.json 與 docs/data/charts/*.json（第一次約 15～20 分鐘，之後有快取）
node serve.js          # 本機預覽 http://localhost:5173
```

`build.js` 會下載每張 mania 譜面，只保留 preview 點開始 12 秒的 note，所以網站不需要碰 osu! API。
音樂直接從 `b.ppy.sh/preview/<setId>.mp3` 播放。

更新題庫：重跑 `node build.js` 後 commit `docs/data`。
